Cómo se usa

Calzada / aceras / casas: toca cada esquina y pulsa «Terminar figura» (mínimo 3 puntos). Público: mantén pulsado y arrastra para rellenar. Seleccionar: toca un objeto y arrastra para moverlo; arrastra un vértice para ajustarlo. Mover vista: arrastra el mapa. Rueda o botones ± para ampliar.

El editor guarda automáticamente en este navegador. Exporta el JSON para enviármelo por el chat e incorporarlo al juego. Este editor no modifica una partida ni publica cambios jugables por sí solo.
