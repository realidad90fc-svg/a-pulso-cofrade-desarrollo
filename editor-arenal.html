Proyecto y herramientas
Este es tu taller. Los cambios se guardan en este navegador. El juego publicado no cambia hasta integrar el JSON exportado.
Visibilidad de capas

Desactiva una capa para dibujar exactamente debajo de ella.

Casas — texturas originales

Elige un edificio del APK y usa «Casa» para dibujar su contorno. Pulsa los puntos de las esquinas y termina con «Cerrar polígono».

Público — sprites del APK

Selecciona «Público» y desliza el dedo para colocarlo. Con «Borrar» puedes despejar la trayectoria del paso.

Superponer tu fotografía aérea

Carga una captura de Google Earth o una foto aérea para calcarla. Queda solo en esta sesión; no se sube a ningún servidor.

Usa «Ajustar foto» para desplazarla por el plano y cuadrarla con Arfe/Adriano.

Probar maniobra del paso

Reproducción de la huella del Tres Caídas (1,04 × 2,15 unidades). Pulsa «Probar paso» para colocarlo y usa los botones para girar.

Esta vista previa orienta, pero las colisiones completas deben comprobarse jugando.

Cómo guardar y usar tu mapa

1. Dibuja o mueve calles, personas, aceras y tejados.

2. Pulsa Guardar para conservar el borrador en este iPhone o PC.

3. Pulsa Exportar mapa para guardar el archivo JSON.

4. Adjunta aquí ese JSON cuando quieras que lo integre en la web del juego.

En ordenador: rueda para zoom, Ctrl+Z para deshacer, Enter para cerrar un polígono y Supr para borrar la selección.
