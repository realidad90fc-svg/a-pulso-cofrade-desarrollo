Proyecto y herramientas
Editor de todos los mapas. Elige un recorrido. Cada mapa guarda su diseño por separado en este navegador. Los originales se muestran como guías basadas en sus colisiones; los cambios se exportan en JSON y no modifican automáticamente el juego.

Visibilidad de capas

Desactiva una capa para dibujar exactamente debajo de ella.

Materiales de tejado · 36 acabados

9 cubiertas originales combinadas con cuatro tratamientos visuales: tradicional, envejecida, clara y oscura. Selecciona una y dibuja una casa, o selecciona una casa existente y pulsa «Aplicar a seleccionado».

Pavimentos y acerados

Los materiales se pueden asignar a las calles y aceras nuevas o a las ya dibujadas con «Seleccionar».

Árboles y vegetación

Los árboles nuevos pueden variar de tamaño y orientación. También puedes moverlos con «Seleccionar».

Cómo guardar y usar tu mapa

1. Dibuja o mueve calles, personas, aceras y tejados.

2. Pulsa Guardar para conservar el mapa y activarlo como borrador jugable en este dominio.

3. Pulsa Exportar mapa para guardar el archivo JSON.

4. Pulsa Publicar mapa para enviar una versión aprobada a GitHub. Solo permite publicar a la cuenta propietaria; necesitarás un token temporal de GitHub con permiso sobre este repositorio. Vercel desplegará después el mapa para todos los visitantes del juego de desarrollo. El enlace principal antiguo no cambia.

En ordenador: rueda para zoom, Ctrl+Z para deshacer, Enter para cerrar un polígono y Supr para borrar la selección.
